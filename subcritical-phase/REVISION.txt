Latest follow-up dated November 3, 2026: occupied passage through oscillating corridors

START WITH occupied-corridors.pdf (source: occupied-corridors.tex).
Theorem 1.1 proves matching logarithmic probability orders -k(log k)^2 for occupied passage through a tube of fixed width following the original oscillating configuration. The remaining Poisson line process and all Cox points are retained. The lower bound simultaneously preserves the original large full-run count. The joint probability including original line selection has the same order.

Proposition 2.1 bounds all routes inside the prescribed tube using separating rectangles and the Poisson exponential formula. Lemma 3.1 bounds any line's total arclength in these rectangles by 5kw. Proposition 2.2 constructs additional groups of nearly parallel lines supporting a continuous occupied path, and Lemma 4.1 preserves the distinct full components. Proposition 5.1 gives exponential decay when only the original selected lines are retained and lambda<1/28.

With M=k^2, the full probability scale is exp(-constant sqrt(M)(log M)^2), which precludes a bound A exp(-aM). This settles the occupied-passage test for this geometry. It does not prove subcriticality or control arbitrary tubes selected from the environment. The upper bound holds for every fixed lambda>0 and therefore does not distinguish phases. See analysis/00-summary.md and analysis/11-occupied-corridors.md for the current assessment.

Latest follow-up dated November 3, 2026: joint cost of oscillating corridors

START WITH oscillating-corridors.pdf (source: oscillating-corridors.tex).
Theorem 1.1 proves a lower bound exp(-C sqrt(M) log(M)) for the existence of an oscillating tuple with at least (K+4)M full connected runs, along an infinite sequence of M, for each fixed mu,K and sufficiently large fixed integer t. The lower bound includes selection of all supporting, base, and repeated generating lines and retains the complete remaining environment.

Proposition 2.1 computes the joint selection probability exactly up to a linear error in its logarithm. Proposition 2.2 uses vacant separating points to keep a positive fraction of the generated intervals in distinct full components. No independence between those vacancy events is assumed.

Consequently, an exponential upper bound A exp(-cM) cannot hold for the unrestricted oscillating extension of the earlier class. This supersedes the suggestion below that joint selection cost might restore that particular tail. The estimates for convex or concave chains remain valid. A weaker uniform upper bound with adequate control across run scales remains a separate open possibility; the lower bound here does not establish it.

The original subcritical percolation problem remains open. No occupied Cox crossing is constructed and no counterexample to positive critical Cox intensity is asserted. See analysis/00-summary.md and analysis/10-oscillating-corridors.md for the current assessment. Earlier records below describe their historical stages.

Latest follow-up dated November 3, 2026: joined corridors

START WITH joined-corridors.pdf (source: joined-corridors.tex).
Theorem 1.1 proves a joint upper-tail estimate for consecutive corridors that share one supporting line. It retains all distinguished lines after insertion and counts the shared line once in the multivariate Mecke formula. The proof uses the fully stated one-family input from corridor-runs.pdf, which remains included.

For two corridors, the full exponential rate is preserved when the shared angle lies between the base-line angles. If both base angles lie on one side, the rate loses a factor of two and the additive allowance increases from four to five. Both cases give a useful joint estimate at fixed large run scale.

The same proof for r base lines has an exponential-rate loss max(p,r-p) and an additive allowance 2r+choose(p,2)+choose(r-p,2), where p base angles lie below the shared angle. These losses grow with r. They are limitations of this proof, not lower bounds showing that a uniform estimate is impossible. Subdividing a segment on one unchanged base line has only a linear boundary allowance and no growing loss in the Poisson comparison.

The required uniform bound across an unbounded number of base-line changes remains open. No subcritical phase theorem or submission-ready proof of positivity is asserted. See analysis/00-summary.md and analysis/07-joined-corridors.md for the current assessment.

Earlier follow-up dated November 3, 2026: connected-run counts in corridors

START WITH corridor-runs.pdf (source: corridor-runs.tex).
Theorem 1.1 proves an exponential upper tail for complete connected runs along any candidate nearly parallel pair in the prescribed corridor. It includes chains of short intervals, boundary components, and selection of the pair from the environment. The proof uses a Poisson comparison for one-family component starts obtained by deleting occupied lengths from the line.

Proposition 4.1 also proves a limitation: concentration at the smaller t^(-3) mean-density scale is impossible. One angular family can persist along a segment of length D with probability of order 1/D and allow order D/t^2 runs of the other family. This lower bound concerns a smaller threshold than the new corridor upper bound and is consistent with it.

The remaining task is joint control when a path moves between many supporting lines or pairs. The full subcritical problem remains open.
