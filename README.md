# Isotropic Poisson line Cox percolation

Christian Hirsch (Göttingen) and Benedikt Jahnel (TU Braunschweig / WIAS Berlin)

Working notes on the planar Boolean model with disks of radius $r$ centred at the points of a Poisson line Cox process: Poisson points of linear intensity $\lambda$ on the lines of an isotropic Poisson line process of intensity $\mu$.

## Contents

| Folder | Content | Status |
|---|---|---|
| `main.tex` (root) | **A supercritical phase for isotropic Poisson line Cox percolation.** Proves $\lambda_c(\mu,r)\le C r^{-1}[1+\log^+(1/(\mu r))]$ and almost-sure percolation above this threshold, by a multiscale argument for closed lattice crossings with deletion of directions. | complete |
| `subcritical-phase/` | **On the subcritical phase.** Quenched zero–one law, quasi-polynomial lower bound on connection probabilities (no exponential decay at any $\lambda$), a quenched path criterion reducing $\lambda_c>0$ to a greedy-path statement about the line process, and an account of why standard methods fail. | open problem; reductions proved |
| `subcritical-phase/greedy-animals/` | **Greedy paths in a Poisson line environment.** Overview of the greedy-lattice-animal approach: linear reward, sandwich identity, bundle densities, failure of first moments and of the dyadic scheme (highways), hierarchical induction as the proposed route. | overview |
| `subcritical-phase/analysis/` | Markdown research notes behind the greedy-animals overview (review of proofs, attempts, obstructions). | notes |

Each LaTeX folder is self-contained: `main.tex`, `jahnel.sty` (preamble), `references.bib`, and `figures/` with the TikZ sources. Compile with `latexmk -pdf main.tex`. The data-driven figures are generated by `figures/make_figures.py` (plain Python 3, no dependencies); the asserts in that script check the geometric claims of each figure.

## Main results

* **Supercritical phase (Theorem 2.1 of the main note).** For every $\mu,r>0$ there is a universal constant $C$ with $\lambda_c(\mu,r)\le Cr^{-1}[1+\log^+(1/(\mu r))]$.
* **No exponential decay (Proposition 4.1 of the subcritical note).** For every $\lambda,\mu,r>0$, the probability of a connection over distance $n$ is at least $\exp(-(4+o(1))(\log n)^2/(\lambda r))$.
* **Quenched path criterion (Theorem 5.1 of the subcritical note).** $\lambda_c(\mu,r)>0$ follows from linear growth of the maximal sum of line counts along lattice paths, a statement about the line process alone (Conjecture 7.2, open).

## Open problem

Positivity of $\lambda_c(\mu,r)$, i.e. existence of a subcritical phase, raised in Hilário, Sá, Sanchis, Teixeira (PTRF 2026, Section 9) and in Jahnel, Jhawar, Vu (EJP 2023). See `subcritical-phase/greedy-animals/main.pdf` for the current state and the proposed strategy.
